## Web App（PWA）

`app/` 是一个 Vite + React 的 PWA，读取 `app/public/data/*.json`，可安装到手机主屏、离线查看。

### 本地运行

```powershell
python scripts/fetch_prices.py     # 更新行情（腾讯，失败自动换东财）
python scripts/build_data.py       # 生成 latest / nav / history / meta
cd app
npm install
npm run dev                        # http://localhost:5173
npm run build                      # 产物在 app/dist
```

### 部署到 GitHub Pages

1. 推到 GitHub 仓库；
2. 仓库 **Settings → Pages → Build and deployment → Source** 选 **GitHub Actions**；
3. 推送到 `main` 后会自动构建部署；也可在 **Actions** 手动运行 `weekly-signal`；
4. 之后每周五北京时间 16:35 自动更新行情、信号并部署；
5. 手机打开 `https://<用户名>.github.io/<仓库名>/`，浏览器菜单里“添加到主屏幕”。

### 自动化说明

- Workflow：`.github/workflows/weekly.yml`，`cron: '35 8 * * 5'`（UTC 08:35 = 北京 16:35）；
- 推送 `main` 和默认手动运行使用仓库中已有数据构建部署；手动运行时可勾选“部署前更新行情和信号”；
- 定时运行会重新抓行情、重算信号、提交 `app/public/data`、构建并部署；
- 抓取失败时脚本非零退出，不会覆盖上一次的数据；
- GitHub 的定时任务可能延迟几分钟，周频策略无影响。
